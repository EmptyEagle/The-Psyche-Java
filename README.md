# The-Psyche-Java

This was my first game project. It was programmed in Java and is playable in the console. This project was an experiment in designing a game using my experience with the programming language. I have since expanded upon this initial demo and have made this into the first chapter out of a total of five planned in a Unity port.

Instructions:
- Download and extract files into the same folder
- Open the terminal console, navigate to the folder, and run _java JavaRPG_
- Enjoy
